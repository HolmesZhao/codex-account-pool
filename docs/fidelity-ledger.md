# 视觉忠实度验收记录

验收日期：2026-09-21

本记录以确认的四张桌面/移动端概念图为基准，在真实 Chromium 中分别检查 1440×960 与 360×800 视口，并用最终截图逐张进行图像对比。

| 检查项 | 实现结果 |
| --- | --- |
| 壳层与导航 | 保留“Codex 号池”品牌及“概览、账号、号池、用户授权、审计”固定文案；桌面为窄侧栏，移动端为紧凑顶栏。 |
| 色彩与表面 | 使用真白背景、冷灰表头/侧栏、深墨蓝文字和青绿色主操作；仅错误与待处理状态使用红/琥珀语义色。 |
| 账号信息层级 | 标题、操作区、四项摘要带、搜索栏、开放式数据表顺序与概念一致；移动端保持平面列表行，没有改成卡片网格。 |
| 号池工作区 | 宽屏保持约 60/40 主从布局；1100px 以下编辑区切换为抽屉，修复了中等视口列表与编辑区相互挤压的问题。 |
| 账号详情 | 桌面使用约 560px 右侧抽屉，移动端使用全屏 Sheet；“登录与凭证、额度、使用情况、账号设置”四区及固定底部操作完整保留。 |
| 图标与控件 | 使用 Lucide 线性图标，按钮、输入框和状态标识保持 8–12px 圆角、细边框与低阴影。 |
| 响应式与键盘 | 360px 无横向溢出；详情关闭后焦点回到触发按钮；抽屉自动获得焦点，并尊重 `prefers-reduced-motion`。 |
| 视觉差异 | 概念图使用演示账号数与样本文案，实际界面展示真实 API 数据；“下载 auth.json”明确改为“下载 AT-only”，避免误导用户会拿到 Refresh Token。账号操作审计位于独立“审计”页，而不是重复铺在账号页底部。 |

浏览器控制台最终检查为 0 个 warning/error。用于验收的截图保存在临时 QA 目录，未写入产品源码或版本库。
